# DataStory Website

Custom website redesign for DataStory, UC Berkeley's student-led data consulting club. Seemless UI with physics based + GPU accelerated animations. Created for DataStory senior advisor presentation.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- GSAP (animations)
- React Router

## Development

```bash
npm i
npm run dev
```
